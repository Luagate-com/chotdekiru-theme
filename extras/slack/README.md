# Chotdekiru Slack Theme

Slack のカスタムテーマで使える、chotdekiru ブランドカラー (`#05B45B`) に揃えた配色。

## インポート方法

1. Slack デスクトップアプリを開く
2. 環境設定 (`Cmd+,`) → テーマ → カスタムテーマ
3. 「インポート」ボタンをクリック
4. 下記の文字列を貼り付け → 「適用」

## Chotdekiru Light

```
#F4F0EA,#A7E5B8,#363635,#E0D7CC,#363635,#05B45B,#F15025,#FFFFFF
```

| 役割 | 色 | 用途 |
|---|---|---|
| Column BG | `#F4F0EA` | 左サイドバー背景 |
| Active Item | `#A7E5B8` | 選択中のチャンネル背景 |
| Active Item Text | `#363635` | 選択中のテキスト |
| Hover Item | `#E0D7CC` | ホバー時 |
| Text Color | `#363635` | サイドバー全体の文字 |
| Active Presence | `#05B45B` | オンライン状態 (ブランド色) |
| Mention Badge | `#F15025` | 未読メンションバッジ |
| Mention Badge Text | `#FFFFFF` | バッジ文字 |
